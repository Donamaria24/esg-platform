# ESG Emissions Management Platform

A full-stack ESG analytics platform built using:

- React.js
- Django REST Framework
- JWT Authentication
- Pandas
- Chart.js
- SQLite

## Features

- CSV Upload
- ESG Emissions Analytics
- Suspicious Record Detection
- JWT Login Authentication
- PDF ESG Report Export
- Interactive Dashboard
- Analyst Review Workflow
